One brutally honest but still polite out-of-office auto-reply — a single
sentence of 88 characters — for the make.fun bounty
[The Painfully Honest Out-of-Office](https://make.fun/bounty/u-po-pu-the-painfully-honest-out-of-office-63e7ca0b).

## The entry

> I am not ignoring you; I am ignoring everything, equally and on purpose, until I return.

It admits the private truth (the sender is ignoring everything on purpose),
opens warmly so no manager objects ("I am not ignoring *you*"), and lands on
a quotable turn of phrase — "equally and on purpose".

## Run

`main.ts` uses only the Node.js standard library. It writes the entry to
`/output/entry.txt` (or `$ENTRY_OUTPUT` when set):

```sh
node main.ts
```

See `trial-log.md` for the candidate shortlist, the field checks against the
live title aggregate, and the bundle/check results.
